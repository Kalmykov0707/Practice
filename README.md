# Калмыков Алан

## Структура проекта

```
Practice/
├── src/
│   └── script.ts        # исходник TypeScript
├── dist/
│   └── script.js        # скомпилированный JS (создаётся автоматически)
├── index.html           # главная страница
├── modal.html           # страница с модальным окном
├── style.css            # стили
├── package.json
├── tsconfig.json
└── README.md
```

## Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/Kalmykov0707/Practice.git
cd Practice
```

Или скачать архив `практика.rar` и распаковать его.

### 2. Установить зависимости

```bash
npm install
```

### 3. Скомпилировать TypeScript

Одноразовая сборка:

```bash
npm run build
```

Или сборка в режиме наблюдения (пересобирает при каждом изменении `.ts`):

```bash
npm run watch
```

После этого в папке `dist/` появится файл `script.js`, который подключается в HTML.

### 4. Запустить сайт

**Вариант А — просто открыть в браузере**

Откройте файл `index.html` двойным кликом. Страница `modal.html` доступна отдельно.

**Вариант Б — локальный сервер (рекомендуется)**

```bash
npx serve
```

или

```bash
npx http-server
```

Терминал выведет адрес, например `http://localhost:3000`. Откройте его в браузере.
## Возможные проблемы

- **`npm run build` ругается на отсутствие `src/script.ts`** — проверьте, что файл `.ts` лежит именно в папке `src/`.
- **Страница пустая, в консоли ошибки** — значит, `dist/script.js` не создан. Выполните `npm run build`.
- **`npx serve` не работает** — просто откройте `index.html` в браузере, для этого проекта этого достаточно.
